HANUMAN BHAKTI WEBSITE

Files:
- index.html
- style.css
- script.js

How to test:
1. Extract the ZIP.
2. Keep all three files in the same folder.
3. Double-click index.html.
4. The site will open in your browser.

Important:
The 50 supplied YouTube/search URLs are stored in script.js.
They are references, not direct MP3/audio files, so browsers cannot play them
through a normal HTML <audio> element.

The website is intentionally structured so each source can later be replaced
with a direct audio URL without redesigning the page.
