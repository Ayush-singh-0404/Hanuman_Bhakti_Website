# Hanuman Bhakti 🚩

A responsive devotional music website featuring a collection of Hanuman and Shri Ram bhajans.

## Live Website

https://ayush-singh-0404.github.io/Hanuman_Bhakti_Website/

## Features

- 17 devotional songs
- Custom audio player
- Play and pause controls
- Previous and next song controls
- Shuffle mode
- Repeat mode
- Seekable progress bar
- Responsive desktop and mobile design
- Automatic handling of audio loading errors
- Consistent SVG player controls across devices

## Built With

- HTML5
- CSS3
- JavaScript
- GitHub Pages

## About

Hanuman Bhakti is a simple devotional music project designed to provide a clean and peaceful listening experience across desktop and mobile devices.
